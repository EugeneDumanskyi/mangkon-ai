# 03 — Non-functional requirements: Mangkon AI v0.1

> Input: `01-brief.md` (approved 2026-09-22) and `02-requirements.md`. **If this file and the brief disagree, the brief wins.**
> Status: Draft for review (2026-10-11).
> Anything marked **ASSUMPTION:** is a guess. Please confirm or correct it. Most speed numbers will be re-checked after the M0 and M1 spikes (milestones as in `06-roadmap.md`).

---

## 1. How to read this file

- Each requirement has an ID (`NFR-<area>-<nn>`), a concrete target, and a way to check it.
- **Source** says where the number comes from:
  - **Brief** = taken from `01-brief.md`.
  - **ASSUMPTION** = a guess. Please confirm or change.
- "p95" = 95% of measurements are at or below this value.
- All speed targets are measured on a **reference machine** (section 2), with the project on an SSD, unless the row says otherwise.
